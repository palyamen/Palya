# TANKS by Astra

Полноэкранная браузерная танковая игра в духе классических 8-битных игр.

## Управление
- Экранный джойстик слева — движение в четырёх направлениях.
- Кнопка «ОГОНЬ» справа — стрельба.
- На компьютере также работают стрелки/WASD и пробел.

## Запуск
Откройте `index.html` через GitHub Pages. Игра рассчитана на горизонтальную ориентацию и подстраивает игровое поле под ширину экрана. После первого открытия файлы кэшируются для офлайн-запуска.

## Публикация
В репозитории откройте Settings → Pages и выберите **GitHub Actions** в разделе Build and deployment. Затем workflow **Deploy TANKS by Astra to GitHub Pages** опубликует папку `tank-city`.

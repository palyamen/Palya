# Rainbow Keyboard

Первая версия клавиатуры для Android.

## Возможности
- Русская и английская раскладки.
- Переключение языков, цифры и знаки.
- Отдельный редактор с предпросмотром, где каждое слово окрашивается в свой цвет.
- Копирование цветного HTML вместе с обычным текстом в буфер обмена.

## Установка на телефон
1. Установить APK.
2. Открыть приложение Rainbow Keyboard.
3. Нажать «Включить клавиатуру» и разрешить её в системных настройках.
4. Вернуться в приложение и нажать «Выбрать Rainbow Keyboard».
5. Для цветного сообщения набрать текст в редакторе и скопировать его.

**Ограничение:** Android-клавиатура обычно передаёт обычный текст. Цветное форматирование зависит от того, поддерживает ли принимающее приложение HTML при вставке. В обычные поля ввода цвета могут не переноситься.

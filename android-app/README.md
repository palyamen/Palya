# TANKS by Astra — Android

Native Android WebView wrapper for the offline HTML5 game.

- Landscape orientation locked by Android.
- Immersive full-screen mode hides status and navigation bars.
- Game is bundled locally in app assets; no internet permission is requested.
- Debug APK is built by GitHub Actions and uploaded as an artifact named `TANKS-by-Astra-APK`.

Application ID: `com.astra.tanks`
Minimum Android: 6.0 (API 23)

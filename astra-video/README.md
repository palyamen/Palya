# Astra Video

Отдельное Android-приложение для поиска видео на YouTube и просмотра роликов во встроенном WebView-плеере.

## Первая версия
- Поиск открывает результаты YouTube внутри приложения.
- Выбор ролика запускает встроенный YouTube-плеер.
- Отдельные вкладки «Поиск», «Плеер», «Загрузки».
- Тёмный интерфейс.

## Ограничения
YouTube Data API key не включён: поиск использует веб-страницу YouTube. Прямое скачивание чужих видео и извлечение MP3 из YouTube не реализуются в обход правил платформы. Раздел загрузок предназначен для материалов, которые пользователь вправе сохранять/экспортировать; офлайн-загрузка YouTube доступна через официальные функции сервиса.
